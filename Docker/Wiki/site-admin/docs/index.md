# Admin guide

Short steps for the things an admin does often. Only people in the group `homelab-admins` can see this page.

| I want to... | Page |
|---|---|
| Let a new friend in | [Invite a friend](invite-a-friend.md) |
| Give or take away access to apps | [Give or remove access](access.md) |
| Stop a person from logging in | [Disable or remove a person](disable-person.md) |
| Help someone who lost their login | [Lost authenticator or password](recovery.md) |
