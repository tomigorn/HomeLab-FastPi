# Notes

Private research notes for one person. MkDocs Material, like the [Wiki](../Wiki/README.md), but the content is **not in this public repo**.

- **URL:** https://notes.holy-grail.ch (Holy Grail SSO, only the user bound to the application)
- **Content:** `NOTES_DIR` in `.env` (`/home/pi/notes`, own local git repo, never pushed; in the fastpi restic backup)
- **Server:** one `caddy:alpine` container serving `$NOTES_DIR/www` read-only, uid 65059

## Add or edit a note

```bash
$EDITOR ~/notes/docs/<topic>.md                 # plus a row in its chapter page docs/chapter-*.md and a nav entry under that chapter in mkdocs.yml
git -C ~/notes add -A && git -C ~/notes commit -m "notes: <topic>"
```

| Step | What happens |
|---|---|
| Save a page | `notes-build.path` runs `build.sh` within seconds: format check, `gen-pages.sh` (generated pages, below), strict build, live at once. Log: `journalctl -u notes-build` |
| Commit | the notes repo's `.git/hooks/pre-commit` (link to `notes-pre-commit`) runs `check-format.sh` on the staged pages |
| By hand | `~/Projects/Docker/Notes/build.sh` |

**Format check** (`check-format.sh`, `-h`; tests: `tests/check-format.sh`): only `claude/batch-backlog.md` (layout from claude-config `batch-homelab.md`: `## Standing run rules`, then `## ✅|❓|⏸️ Title (repo)` per open item, intro line, blank line, `- ` list; done items deleted), `claude/reminders.md` (table rows complete) and `claude/reports/<date>.md` (title names the date). All checked pages: blank line before a list; backlog and reminders: lines ≤ 400 characters.

## Claude section (`docs/claude/`)

| Page | Source |
|---|---|
| `batch-backlog.md`, `reminders.md`, `batches/<date>.md` | written by Claude (batch rules: claude-config `batch-homelab.md`) |
| `reports/<date>.md` | one batch report per date, kept forever; several runs = one `##` section each; `reports/<date>-shots/` images, `reports/archive/<date>/` older material (Oct–Nov 2026, Markdown from `~/reports`) |
| `recent.md`, `claude/batches/index.md`, `claude/reports/index.md` | generated by `gen-pages.sh` |
| `claude/roadmaps/<repo>.md` | generated: copy of each repo's `docs/roadmap.md` or `docs/working/roadmap.md` (`ROADMAP_REPOS` in `gen-pages.sh`), links into the repo become plain text |
| `claude/open-questions.md` | generated: roadmaps' Open questions, the latest report's ❓ sections, the reminders' open table |
| `claude/due-dates.md` | generated: `Docker/Due-Dates` list (`due_dates.py md` over `/var/lib/due-dates/due-dates.json`, env `DUE_DATES_JSON`); refreshed on every notes build |
| all generated pages above | gitignored in `~/notes`, never committed: the build writes them |
`gen-pages.sh -h`; tests: `tests/gen-pages.sh`. `docs/working/` is never published (`exclude_docs`). Old URLs (`/batch-backlog/`, `/reminders/`, `/batches/…`) redirect in the `Caddyfile`.

**Install** (once): `sudo install -m 0644 systemd/notes-build.* /etc/systemd/system/ && sudo systemctl daemon-reload && sudo systemctl enable --now notes-build.path`; hook: `ln -s ~/Projects/Docker/Notes/notes-pre-commit ~/notes/.git/hooks/pre-commit`.

## Access

| What | How |
|---|---|
| Provider `notes-proxy`, application `notes` | `../Authentik/scripts/provision-notes-sso.py` |
| Who gets in | a direct **user** binding on the application, no group: `docker compose exec -T -e NOTES_USER=<username> server ak shell < scripts/provision-notes-sso.py` (in `../Authentik`) |
| Test with the canary | `-e CANARY=add`, then `../Authentik/scripts/canary-verify.sh https://notes.holy-grail.ch/ "Research notes"`, then `-e CANARY=remove`; unbound the same check must fail |
| Remove | `-e REMOVE=1` |

## Wiring

```
Internet → Cloudflare Tunnel (route notes.holy-grail.ch → https://192.168.1.2:443, No TLS Verify)
  → Traefik router notes (authentik@file, default-rate-limit, notes-secure-headers: CSP, no-store, noindex)
  → http://notes:80
```

LAN and VPN reach it through the AdGuard `*.holy-grail.ch` rewrite without the tunnel route.
